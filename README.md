# Task Management Application

## Overview

Task Management Application is a web-based application that helps users create, manage, and track their daily tasks efficiently. The application provides an easy-to-use interface for adding and deleting tasks.

## Features

* Add New Tasks
* Delete Existing Tasks
* Simple and User-Friendly Interface
* Responsive Design
* Real-Time Task Updates on the Page

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

Task-Management-App

├── index.html

├── style.css

├── script.js

└── README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start adding and managing tasks.
